# 데이터 레퍼런스 — CMS 참가기관별 계좌번호 체계

PDF 표를 기관 단위로 전수 전사한 부분이다. 라이브러리 레지스트리 (`src/registry/`) 의 1차 진실원본이며, 표의 행 하나가 코드의 `AccountPattern` 하나에 대응한다.

> **계정과목 카테고리(10종, PDF 표 칼럼 순서):** `보통 / 국고 / 저축 / 자유저축 / 가계당좌 / 당좌 / 기업자유 / YES / 연계 / 기타`

<a id="0-식별-위치-패턴-개발자-핵심"></a>

## 0. 식별 위치 패턴 (개발자 핵심)

CMS 계좌번호는 기관·자릿수에 따라 **계정과목 코드(과목코드)의 위치가 다릅니다.** 다음 4가지 패턴 중 하나로 떨어집니다.

| 패턴                   | 구조                          | 과목코드 위치          | 대표 예                                                                                                                                                                       |
| ---------------------- | ----------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A. 앞 (Front)**      | `과목 - 일련 - 검증`          | 1–3번째 자리           | 차세대 신계좌 대부분 (산업 14, 하나 12 차세대, 농협 13, 부산 13, 경남 13, 신협 12, 새마을금고 13, 우체국 12, 신한 12, 토스 12 등)                                             |
| **B. 가운데 (Middle)** | `점번호 - 과목 - 일련 - 검증` | 4–5번째(또는 5–6, 7–8) | 구계좌 다수 (산업 11, 기업 12, 국민 12, 하나 11, 우리 구상업/한일/평화, 한국씨티 11/13, 부산 12, 광주 12, 제주 10, 전북 12, 경남 12, 부국 11, 케이프 11 등 / 농협 14 7–8번째) |
| **C. 뒤 (End)**        | `일련 - 검증 - 과목`          | 마지막 2자리           | 키움 10, 아이엠증권 10, 메리츠 10, 하나금융투자 10, 하나증권 14, HSBC 12(끝 3자리)                                                                                            |
| **D. 없음**            | 과목코드 미사용               | 없음                   | 삼성/한국투자/NH/SK/대신/한화/유진/카카오페이/신영 등 다수 증권사, 신협 10/11, K뱅크 13, 카뱅 등                                                                              |

> **반드시 [기관 코드 + 자릿수] 조합으로 매칭하세요.** 같은 기관도 자릿수마다 체계가 완전히 다릅니다.

<a id="4-개발자-체크리스트"></a>

## 4. 개발자 체크리스트

1. **매칭 키**: `대표코드 + 자릿수 + 첫 1–3자리 패턴` (특히 인터넷전문은행/가상계좌).
2. **과목코드 위치**: 같은 기관도 자릿수마다 위치가 다름. 단일 정규식만으로는 충분하지 않음.
3. **수협 분기 처리**:
   - 11자리: 4·5번째 자리가 43–45,47,49,59,61–64,66–68,74,75,78,81–85,93 → 030, 그 외 → 007
   - 12자리: 1번째 자리가 2/7/9 → 030, 그 외 → 007
   - 14자리: 1·2·3번째 자리가 493, 481–489 → 030, 그 외 → 007
   - 수협중앙회 12자리 (반대 방향): 1번째 자리가 2/7/9면 030 유지, 그 외 → 007
4. **농협 차세대 13자리**: 과목코드 (앞 3자리) 만으로 보통/저축 등을 분류. 끝자리(계좌구분) 의 1·2=구가상, 3·4·5=입금전용(적금·신탁) 규칙은 _과목코드가 적금/신탁_ (304·310·314·321·324·334·345·347·349·359·380 / 028·031·043·046·079·081·086·087·088 / 354·360·384·394·398) 일 때만 적용. 일반 과목코드(301·302·312·306·305·317 / 351·352·356·355)는 끝자리 무관.
5. **K뱅크 식별**: 10자리 첫자리=9(입금전용), 14자리 첫자리=7 또는 9(간편송금/안심계좌).
6. **토스뱅크 식별**: 12자리 첫 2자리=17 또는 19 → 가상계좌.
7. **국민은행 11자리**: 첫자리=0(고객지정/핸드폰, 입금만) vs 9(평생계좌·자유입출금).
8. **체크디지트**:
   - 광주은행 12자리(과목 731)은 **검증 X**
   - 수협(007/030)은 분리 시행 이후 **검증 안함**
   - 그 외 대부분 마지막 1자리에 위치
9. **출금이체 제한 계좌**:
   - 평생계좌 (기업·하나·하나증권)
   - 가상계좌 대부분 (입금만)
   - 서비스 미참가 외국계: HSBC(054), 도이치(055), 제이피모간(057), BNP파리바(061)
10. **사명 변경 매핑**: 신한투자증권(구 신한금융투자), 아이엠뱅크(구 대구), 아이엠증권(구 하이투자), 엘에스증권(구 이베스트), 우리투자증권(구 한국포스), 메리츠증권(구 메리츠종금), 하나증권(구 하나금융투자), 현대차증권(구 HMC), NH투자증권(구 우리투자+NH농협).

## 6. KFTC 표준은행코드 vs CMS 참가기관 코드

두 코드 체계는 모두 KFTC 가 운영하지만 **별도 namespace** 다. 같은 institution 이 두 체계에서 다른 코드를 가질 수 있다.

| 항목            | CMS 참가기관 코드 (라이브러리 `Institution.code`) | 표준은행코드 (라이브러리 `Institution.commonCode`)         |
| --------------- | ------------------------------------------------- | ---------------------------------------------------------- |
| 출처            | 금융결제원 CMS EDI PDF (이 문서)                  | 금융공동망 공동코드                                        |
| 용도            | CMS 자동이체·공과금 시스템 식별                   | 일반 송금/이체 시스템 식별                                 |
| 라이브러리 노출 | `Institution.code` (모든 institution 에 필수)     | `Institution.commonCode` (CMS 와 다를 때만 지정, optional) |

<a id="62-사용-패턴"></a>

### 6.2 사용 패턴

```ts
import { detectBest } from "korean-account";

// 표준은행코드 기반 서버를 쓰는 컨슈머
const top = detectBest("161-910278-72907");
const bankCode = top?.institution.commonCode ?? top?.institution.code;
//                                              ↑ fallback (대부분 동일)
// → "081" (하나은행 표준)

// CMS namespace 컨슈머는 그대로 .code 사용
const cmsCode = top?.institution.code;
// → "005" (하나은행 CMS)
```

<a id="63-mismatch-는-하나은행뿐--나머지는-두-namespace-동일"></a>

### 6.3 mismatch 는 하나은행뿐 — 나머지는 두 namespace 동일

등록 기관 중 CMS `code` 와 표준은행코드가 갈라지는 곳은 하나은행 (005 ↔ 081) 하나다. 나머지는 두 namespace 의 코드가 동일해 `commonCode` 를 생략하며, `src/registry/common-code.spec.ts` 가 이를 회귀 가드로 고정한다. 농협중앙회(012) ↔ 표준 012 (지역농·축협), 외국계 미참가 4곳 (054/055/057/061) 모두 동일 번호이고, 수협 분리 (2025.11.10) 도 CMS·표준 양쪽에 같은 코드로 시행됐다 — 수협은행 007 (지점 009) / 수협중앙회 030 (지점 069·070). ([KFTC 공지](https://www.cmsedi.or.kr/edi/board/notice/view/1006))

**CMS 코드 `081` 주의** — PDF § 3 은 081 을 하나은행 별칭 set ("005 하나은행: 025, 033, 080, 081, 082") 에도 올려 두지만, CMS namespace 에서 081 의 대표 주인은 별개 기관인 _하나증권 CMA_ 다. 라이브러리는 충돌을 피해 `hana.aliasCodes` 에서 081 을 제외하므로 `getInstitution("081")` 은 하나증권 CMA 를 반환한다. 하나은행의 표준은행코드가 필요하면 `hana.commonCode` (`"081"`) 를 읽는다 (§ 6.2 패턴).
