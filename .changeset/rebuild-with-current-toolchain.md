0.3.0 은 `tsdown` 0.22 로 빌드됐다. 0.23 으로 올리면서 타입 선언 생성
방식이 바뀌어, 배포본과 저장소가 만드는 결과물이 달라진 상태였다.

- 런타임 JavaScript: **변화 없음** (dist 의 JS 369 개가 바이트 단위로 동일)
- 타입 선언: 말미의 `export { ... }` 블록 대신 `export declare` 를 인라인으로
  내보내는 형태로 바뀌었다. **내보내는 심볼은 전부 동일하다** — 공개 타입
  표면이 그대로라 타입 검사 결과도 달라지지 않는다.

동작 변화가 없는 재빌드 릴리스다. 업그레이드해도 코드를 고칠 일은 없다.
